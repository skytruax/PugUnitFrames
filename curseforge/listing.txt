What goes in which field of the CurseForge project form (World of Warcraft > Addons).
The project does not exist yet: you create it by hand at https://authors.curseforge.com/
(Create a project > World of Warcraft > Addons). Everything below is ready to paste or upload.

Name
    Free Unit Frames - PitBull-Style, Lighter, Ready to Play

    56 characters. It says what you asked for (like PitBull, but better) in two things that are
    true today: lighter (one small folder, no libraries) and ready to play (no setup). PitBull's
    own page lists Retail, MoP Classic, Classic and Classic TBC and no Forever (looked at on
    2026-11-23), so "PitBull-style" is also what a PitBull player on Forever will type.

    Why "Forever" is in the summary and not in the name: CurseForge's Moderation Policies say
    "Names should not contain game name, class name versions, file versions ect...." Other
    projects have the word in their names and are listed, so it is not always enforced, but a
    rejected name costs a day.

    Why not "better": it is a claim PitBull's players will test against PitBull's options, of
    which it has far more than a first version does. If you want it said anyway:
        Free Unit Frames - Like PitBull for Forever, but Better     (also has the game's name in it)
    Without the other addon's name at all:
        Free Unit Frames - Light Player, Target, Party & Raid Frames

Summary
    PitBull-style unit frames written from scratch for Forever: clean class-coloured player, target, focus, pet, party and raid frames that keep working in combat, with auras, cast bars, threat, range and dispel highlights. Light, no libraries, no setup.

    250 characters; the field takes 256 and asks for one clear sentence. Search matches the name
    and the summary, so between them they carry what people type: unit frames, PitBull, Forever,
    party, raid, auras, cast bars.

Logo
    curseforge/logo.png (400 x 400): the bronze compass ring of FreeControl's emblem with three
    bars on its disc, so the two addons look like one family.

Description
    curseforge/description.html, pasted into the editor's source view (the "<>" button).
    It is built from description.md by: python3 tools/make_listing.py description
    Its pictures are seven of the gallery pictures at a smaller size (curseforge/web/, loaded from
    GitHub), so there is nothing to upload for them. The "?v=" on each link is there so that a
    changed picture is fetched afresh: raise it in description.md when the pictures change.

Images, in this order
    your own screenshots from the game first, then curseforge/gallery/01-hero.png to
    08-logo.png (1920 x 1080 each). They are illustrations and say so on the picture, with
    the game's own spell icons and raid marks on the frames, credited to Blizzard on each one.

File: the first one goes up by hand
    dist/FreeUnitFrames-0.1.0.zip   (tools/package.sh builds it; dist/ is not in the repository)
    Release type    Release
    Game version    World of Warcraft: Forever, 1.60.1
    Changelog       the v0.1.0 section of CHANGELOG.md (markup type: Markdown)
    A new project, and each new file, is public once CurseForge has reviewed it.

Later versions: by pushing a tag
    Once the project exists it has an id (the number in its author-console address).
    1. Put it in FreeUnitFrames/FreeUnitFrames.toc as a line "## X-Curse-Project-ID: <id>".
    2. Give this repository the upload token as a secret named CF_API_TOKEN. It is the author
       API token FreeControl's repository already uses (authors.curseforge.com > API tokens);
       the Core API key you can apply for separately is a different thing and is not needed
       for any of this. With gh: gh secret set CF_API_TOKEN -R skytruax/FreeUnitFrames
    3. Push a version tag (git tag -a v0.1.1 -m "Free Unit Frames 0.1.1"; git push origin v0.1.1).
       The release workflow builds the zip, makes a GitHub release and sends the file to
       CurseForge with CHANGELOG.md as its changelog.

GitHub
    docs/social.png goes in the repository's Settings > Social preview (that one cannot be set
    from the command line).

Relations
    none. Free Unit Frames needs no other addon.
