What goes in which field of the CurseForge project form (World of Warcraft > Addons).

Project
    id 1826652, created by hand on 2026-11-23
    https://authors.curseforge.com/#/projects/1826652/general
    public page, once CurseForge has reviewed it: https://www.curseforge.com/projects/1826652

Name
    Free Unit Frames - PitBull-Style, but Lighter: Player, Target, Focus, Pet, Party & Raid Frames with Cast Bars, Auras and Threat

    127 characters; the field takes 128. Search matches the name first, so the long form carries
    what people type (PitBull, unit frames, party, raid, cast bars, auras). A page shows only the
    first forty or so characters in a list, which is why "Free Unit Frames - PitBull-Style" comes
    first. The short form, if the long one reads as too much:
        Free Unit Frames - PitBull-Style, Lighter, Ready to Play          (56 characters)

    The page's address is its own thing: FreeControl's is "free-control" although its name is
    longer. I have not seen the create form, so look at the address it proposes before you
    confirm. If it follows the long name, create the project as "Free Unit Frames" (which gives
    curseforge.com/wow/addons/free-unit-frames) and put the long name in afterwards, on the
    project's settings page.

    It says what you asked for (like PitBull, but better) in something that is true today:
    lighter (one small folder, no libraries, no setup). PitBull's own page lists Retail, MoP
    Classic, Classic and Classic TBC and no Forever (looked at on 2026-11-23), so "PitBull-style"
    is also what a PitBull player on Forever will type.

    Why "Forever" is in the summary and not in the name: CurseForge's Moderation Policies say
    "Names should not contain game name, class name versions, file versions ect...." Other
    projects have the word in their names and are listed, so it is not always enforced, but a
    rejected name costs a day.

    Why not "better": it is a claim PitBull's players will test against PitBull's options, of
    which it has far more than a first version does. If you want it said anyway (128 characters,
    and it has the game's name in it):
        Free Unit Frames - Like PitBull for Forever, but Better: Player, Target, Focus, Party & Raid Frames, Cast Bars, Auras and Threat
    Without the other addon's name at all:
        Free Unit Frames - Light Player, Target, Party & Raid Frames

Summary
    PitBull-style unit frames written from scratch for Forever: clean class-coloured player, target, focus, pet, party and raid frames that keep working in combat, with auras, cast bars, threat, range and dispel highlights. Light, no libraries, no setup.

    250 characters; the field takes 256 and asks for one clear sentence. Search matches the name
    and the summary, so between them they carry what people type: unit frames, PitBull, Forever,
    party, raid, auras, cast bars.

Description
    curseforge/description.html, pasted into the editor's source view (the "<>" button).
    It is built from description.md by: python3 tools/make_listing.py description
    Its pictures are stored on GitHub, as FreeControl's are: the moving demo (docs/demo.gif) and
    seven of the gallery pictures at a smaller size (curseforge/web/). The page loads them from
    there, so there is nothing to upload for them. The "?v=" on each link is there so that a
    changed picture is fetched afresh: raise it in description.md when the pictures change.

Images, in this order
    your own screenshots from the game first, then curseforge/gallery/01-hero.png, 09-in-play.png,
    and 02-frames.png to 08-logo.png (1920 x 1080 each). 09-in-play is the addon's own code
    drawing a fight in the simulator; the others are illustrations. Each says on the picture what
    it is, and credits the game's spell icons and raid marks on the frames to Blizzard.

Later versions: by pushing a tag
    1. The project id is in FreeUnitFrames/FreeUnitFrames.toc ("## X-Curse-Project-ID: 1826652").
    2. This repository has the upload token as a secret named CF_API_TOKEN (since 2026-11-23).
       It is the author API token FreeControl's repository uses (authors.curseforge.com > API
       tokens), and it is the account's, not one project's. The Core API key you can apply for
       separately is a different thing and is not needed for any of this.
    3. Push a version tag (git tag -a v0.1.1 -m "Free Unit Frames 0.1.1"; git push origin v0.1.1).
       The release workflow builds the zip, makes a GitHub release and sends the file to
       CurseForge with CHANGELOG.md as its changelog.
    v0.1.0 was tagged before the secret was there, so it is a GitHub release only and the 0.1.0
    on CurseForge is the one uploaded by hand. Running that workflow again now would send a
    second 0.1.0 to CurseForge: leave it be. v0.1.1 is the same addon, published by the workflow
    to both.
